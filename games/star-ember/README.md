# 星烬：最后一夜（Star Ember: The Last Night）

霓虹废墟题材的俯视角像素动作肉鸽网页游戏。纯 HTML + CSS + 原生 JavaScript + Canvas 实现，
所有像素美术、音效、地图均由程序运行时生成，**零外部素材、零依赖、离线可玩**。

## 运行方式

方式一（推荐）：直接双击 `index.html` 在浏览器中打开。

方式二：本地服务器
```bash
node serve.js
# 浏览器访问 http://127.0.0.1:8123/
```

自动化自检：访问 `http://127.0.0.1:8123/?selftest=1`（或直接打开 `index.html?selftest=1`），
会自动运行 36 项流程验证并在页面左下角显示结果；控制台也可随时调用 `__TEST.run()`。

## 玩法目标

一局约 10 分钟：击杀敌人 → 拾取经验晶体 → 升级三选一构筑 → 敌人随时间增强。
- **4:30** 出现中期首领「残响巨像」（环形弹幕 / 扇形齐射 / 召唤）
- **9:00** 出现最终首领「星烬主宰」，按剩余生命切换 3 个阶段（弹环 / 旋臂弹幕 / 冲锋 / 召唤 / 新星环，全部带预警）
- 击败最终首领即胜利；坚持到 10 分钟不会自动获胜，必须亲手终结它。

## 已实现内容

- **玩家**：生命 / 移速 / 伤害 / 攻速 / 暴击 / 拾取范围属性，自动索敌射击、冲刺残影 + 无敌帧 + 冷却指示、受击无敌与击退、像素伤害数字、屏幕震动。
- **敌人**：追逐者、距离型射手（预警后射击）、蓄力冲锋者（预警线 + 直线冲锋）、重装怪、金色描边精英（固定时间点出现，高属性高掉落）。
- **首领**：两个独立像素绘制首领，顶部名牌血条、多套攻击 + 全部带预警演出、狂暴与阶段切换清弹幕。
- **强化**（14 种 + 2 种保底补给）：伤害、攻速、多重弹、穿透、暴击、移速、生命上限、拾取范围、冲刺冷却、命中减速、环绕刀刃、浮游无人机、生命再生、星火核心；多数可叠加有上限，满级项不再出现在候选中。
- **界面**：中文标题/菜单/暂停/升级/结算（胜败不同配色文案）、Boss 血条、经验条、计时、击杀、得分、冲刺冷却、低血量警示、声音开关（M）、最高得分/最长生存/最高等级 localStorage 记录。
- **场景**：程序生成网格废墟地面（裂纹、残骸、发光碎片、断裂钢梁、霓虹水洼、边界警戒栅栏、漂浮余烬），逐局随机种子。
- **音效**：WebAudio 程序化合成（射击、暴击、受伤、冲刺、拾取、升级、首领警报等）+ 极简背景律动，Boss 战变奏。
- **性能**：固定 60Hz 步长、空间哈希碰撞、实体数量上限（敌人 ≤220、敌弹 ≤320、粒子 ≤520、晶体超限自动合并），220 敌 + 300 弹实测 600 帧更新仅约 92ms。

## 项目结构

```
index.html      入口页面与 DOM 结构
css/style.css   界面样式（霓虹像素风、CRT 扫描线、触屏控件）
js/core.js      全局状态 / 常量 / 输入系统
js/util.js      数学、随机、像素字体
js/audio.js     WebAudio 音效与背景律动
js/sprites.js   全部程序化像素美术（角色/怪物/首领/图标）
js/data.js      数值配置（波次、敌人、首领、强化卡）
js/entities.js  玩家 / 敌人 / 首领 AI / 子弹 / 拾取 / 粒子
js/game.js      主循环、导演、空间网格、渲染
js/ui.js        HUD、菜单、卡牌、触屏、缩放
js/test.js      36 项自动化验证（?selftest=1）
serve.js        可选的本地静态服务器
```

## 验证结论（2026-10-25 实测）

在 Chromium 中通过 `?selftest=1` 实际运行验证：**36/36 通过**，覆盖
开始/移动/自动攻击/击杀掉经验/拾取升级/三选一生效/受伤无敌/暂停冻结/双首领生成与阶段切换/
胜利与死亡结算/记录保存/重开重置/性能与实体上限/无运行期报错。
另实测 11 分钟整局模拟：首领分别于 273.9s、544.5s 出现，实体全程受控，超时不会自动获胜。
