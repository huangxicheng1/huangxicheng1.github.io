## Agent / Harness

### [OpenManus 和 Claude Code：两种 Agent 骨架的差别](https://huangxicheng1.github.io/openmanus-vs-claude-code.html)

- **一句话**：OpenManus 回答「agent 怎么跑起来」，Claude Code 回答「跑起来之后怎么不跑崩」——差别不在继承层数，而在主循环里写了几条出口。
- **覆盖**：四层继承链 vs 扁平状态机 · 主循环的四条出口（两条正常 + 两条恢复）· 失败粒度（整个任务 vs 单次调用）· 止损策略（重复检测 vs 预算上限）· 继承式扩展 vs 配置式扩展 · 十项速查对比
- **适合**：准备 agent / harness 方向的面试；或者想搞清楚「能跑通的 demo」和「能上线的 agent」差在哪一步
- **形态**：单文件 HTML，零外部依赖，可离线打开；含继承链树、出口分支表、失败粒度作用域树
- **更新**：2026-11-18

## 维护说明

- 页面文件放在仓库根目录或子目录，并**必须**加进 `.github/workflows/pages.yml` 里 `cp` 那行的白名单，否则工作流不会把它拷进 `dist/`，发布了也是 404
- 本页就是 `content/notes/` 下的普通笔记，改完提交即可；部署时工作流会跑 `build.py` 重新生成 `entries.js`
- `gallery/`、`games/`、`todo/`、`vault/` 是站点功能模块，不算学习资料，不登记在这里
