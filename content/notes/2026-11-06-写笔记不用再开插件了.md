## 为什么要有这个页面

以前想改一篇笔记，得回到本地打开编辑器、改 Markdown、commit、push——写一句想法要过五道手续。现在直接在站上写：左边写 Markdown，右边就是它上线后的样子，保存即提交。

## 它是怎么工作的

内容真相仍然是那一个 `content/**/*.md`，没有数据库：

- 保存时通过 GitHub 接口把文件提交进仓库
- Actions 跑 `build.py` 重新生成索引
- 大约一分钟后，这里就能看到

也就是说，站上写和本地写产生的是同一种文件，随时可以改回来。

## 已经有的

| 能力 | 说明 |
| --- | --- |
| 三个入口 | 编辑室、笔记库的「＋ 写一条」、阅读页的「编辑」 |
| 实时预览 | 和线上同一套渲染，不会所见非所得 |
| 插图 | 直接粘贴图片，自动传进仓库 |
| 草稿 | 先存成草稿，想发再发 |
| 归档 | 不删文件，只是从站上摘下来，随时恢复 |

## 还没做的

删除按钮暂时没有——归档已经够用，真删还是留给 git 历史。
