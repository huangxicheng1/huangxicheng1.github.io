先授一次权

编辑器通过 GitHub 接口把文件直接提交到仓库，所以需要一枚 token——只对本仓库的 Contents 有读写权限、只存在这台浏览器的 localStorage 里，不进仓库，也不会发给 api.github.com 以外的任何地方。

  1. 打开 GitHub · Fine-grained personal access tokens
  2. Repository access 只选 huangxicheng1.github.io
  3. Permissions → Contents 选 Read and write（其余全都不需要）
  4. 生成后粘到下面，只输一次；换浏览器要重输

和站内批注用的是同一枚 token，授权一次两边都能用。
